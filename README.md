# IC3 Quizz

Ứng dụng luyện thi trắc nghiệm bằng React + Tailwind CSS + Firebase.

Quick start:

1. Cài dependencies

```bash
npm install
```

2. Chạy dev server

```bash
npm run dev
```

3. Thiết lập Firebase

- Tạo một project trên Firebase console
- Thêm Web app và copy config vào `src/firebase.js`
- Bật Authentication (Email/Password) và Firestore nếu cần

Tiếp theo tôi sẽ kết nối Tailwind chính xác và thêm ví dụ xác thực/Firebase.
